# Testnet Results

This document is reserved for reproducible ASENDEX / Asentum testnet observations.

## Evidence template

```text
Observed at (UTC):
Chain ID:
Endpoint / node:
Block height:
Block hash:
Parent hash:
Block timestamp:
Transaction hash (if applicable):
Expected behavior:
Observed behavior:
Reproduced on another independent endpoint/node: YES / NO / NOT AVAILABLE
Classification: observation / confirmed cross-node / interpretation
Notes:
```

## Rules

Do not rewrite historical observations after a reset. Instead, record the new genesis/chain context and clearly mark which observations belong to which testnet state.

A local validator fork, crash or failed RPC request is evidence about that observation point; it is not by itself proof that the entire network failed.
