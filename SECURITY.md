# Security Policy

ASENDEX is experimental testnet software.

## Never report secrets publicly

Do not open an issue containing seed phrases, private keys, validator keys, API secrets, access tokens or other credentials.

## Reporting a vulnerability

For non-sensitive bugs, open a GitHub issue with reproducible steps, expected behavior, actual behavior, network/chain information and transaction or block identifiers when applicable.

For a vulnerability that could expose keys, assets or infrastructure, contact the repository owner privately before publishing technical exploitation details.

## Scope

Useful reports include incorrect balance/accounting behavior, transactions reported as confirmed when reverted, RPC inconsistency, persistent block-hash divergence, contract issues, unsafe wallet handling, and misleading network-health reporting.

## Testnet warning

Do not send mainnet assets to ASENDEX testnet contracts or addresses. Never commit wallet or validator secrets to this repository.
